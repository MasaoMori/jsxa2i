# 日本応用情報学学術交流連合 定款（案）

**Japan Scholarly Exchange Alliance for Applied Informatics（JSXA²I）**

改訂第6案　2026年11月20日

---

## 第1章　総則

### 第1条（名称）

本連合体は、日本応用情報学学術交流連合と称し、英文名称を *Japan Scholarly Exchange Alliance for Applied Informatics*、略称をJSXA²Iとする。

2. 電子的な情報処理等において上付き文字の使用が困難な場合には、略称をJSXA2Iと表記することができる。

### 第2条（組織の性格）

1. 本連合体は、日本国内の複数の学術団体が、応用情報学及びその関連領域における共通の目的の下に協働する非営利の連合体とする。
2. 本連合体は、構成団体の独立性及び学術的自律性を尊重し、それぞれの目的、組織及び学術活動を維持した上で、相互に対等な立場で協働する。
3. 本連合体は、構成団体の統合又は上位組織への再編を目的としない。
4. 本連合体は、法人格を有しない任意団体として組織する。

### 第3条（目的）

1. 本連合体は、日本国内の応用情報学及びその関連領域における複数の学術団体が、それぞれの独立性と学術的自律性を維持しながら、学術的知識の共有と流通に関する共通の方針及び仕組みを形成し、共同で推進することを目的とする。
2. 本連合体は、構成団体が蓄積してきた研究成果及び学術的知見を、個々の学術領域や組織の境界を越えて相互に結び付けることにより、国内外への学術情報の流通、学術交流及び新たな知識の創造を促進する。
3. 本連合体は、新たな学術団体の参加を通じて学術的知識の連携を拡大し、持続的かつ開かれた学術情報流通の環境の形成に寄与する。

### 第4条（基本原則）

本連合体は、次の基本原則に基づいて活動する。

1. **学術情報の国内外への流通**  
   学術情報が組織、学術領域、国境及び言語の障壁を越えて発見、理解、参照及び活用されることを促進する。

2. **学際的な知識交流**  
   異なる学術領域における知識、研究方法及び実践的知見の相互交流を促進し、新たな学術的知識の創造に寄与する。

3. **公開性と相互運用性**  
   学術情報の適切な公開と再利用を支援するとともに、学術情報の国際的な永続的識別子（Persistent Identifier：PID）及びメタデータ標準等を活用し、学術情報の発見可能性、参照可能性及び相互運用性の向上を推進する。

4. **学術的自律性と協働**  
   各構成団体の独立性と専門性を尊重し、対等な立場で共通の課題に取り組む。

5. **信頼性と責任ある利用**  
   学術情報の信頼性、研究倫理、著作権及び情報の出典を尊重し、適切な情報の流通と利用を推進する。

6. **持続的な知識の共有と継承**  
   学術情報の長期的な参照可能性を重視し、特定の技術又は情報サービスに過度に依存しない、持続可能な知識共有の環境の形成を目指す。

## 第2章　事業

### 第5条（事業）

本連合体は、第3条の目的を達成するため、次の事業を行う。

1. **学術情報の国内外への流通の促進**  
   構成団体が創出又は公開する学術情報を相互に結び付け、学術領域及び組織の境界を越えた国内外への紹介、発見、参照及び流通を促進する。

2. **学術交流及び連携の促進**  
   構成団体間の継続的な交流と連携を促進するとともに、国内外の学術団体、研究者及び実践者との協働関係を形成する。

3. **学術分野横断的な知識共有の促進**  
   異なる学術領域における研究成果、研究方法及び実践的知見を相互に共有し、共通する学術的課題の発見と新たな知識の創造を促進する。

4. **学術情報の相互運用性の向上**  
   学術団体間における学術情報の発見、参照及び再利用を促進するため、永続的識別子（PID）やメタデータ標準等を活用し、学術情報の流通及び連携に関する共通の方針と仕組みを形成し、その継続的な運用と発展を図る。

5. その他、本連合体の目的を達成するために必要な事業。

### 第6条（事業実施の原則）

1. 本連合体の事業は、複数の構成団体の協働によって学術的又は社会的な価値が生じる活動を中心とする。
2. 本連合体は、構成団体が独自に実施する学術出版、学術集会、研究交流その他の活動を原則として代替せず、それらの相互の連携及び発展を支援する。
3. 本連合体は、構成団体に共通する課題について協議し、必要に応じて共通方針を形成するとともに、その実現に向けた協働を推進する。
4. 個々の共同事業への参加は構成団体の自主的な判断に基づくものとし、事業実施上の役割及び責任は、関係する構成団体の合意により定める。
5. 本連合体は、事業の実施に当たり、既存の国内外の学術情報基盤及び標準を尊重し、それらの活用と連携を基本とする。

## 第3章　構成団体及び協力機関

### 第7条（構成団体）

1. 本連合体は、日本国内に主たる活動拠点を置き、その目的及び基本原則に賛同する学術団体をもって構成する。
2. 構成団体は、それぞれの定款、規程及び意思決定手続を維持する。
3. 本連合体は、応用情報学及び関連領域との学術的な連携可能性を踏まえ、国内の多様な学術団体に対して参加の機会を開く。
4. 構成団体に所属する個人は、本連合体への個別の加入を要しない。

### 第8条（構成団体の参加）

1. 本連合体への参加を希望する学術団体は、運営協議会に参加を申請するものとする。
2. 新たな構成団体の参加は、既存の構成団体総数の3分の2以上の賛成をもって承認する。
3. 参加の承認に当たっては、本連合体の目的及び基本原則との整合性を重視する。

### 第9条（構成団体の権利及び責務）

1. 構成団体は、本連合体の意思決定に対して対等な議決権を有する。
2. 構成団体は、本連合体の目的及び基本原則を尊重し、合意した活動の実施に協力する。
3. 本連合体への参加は、構成団体が保有する学術情報、著作権その他の権利の移転を意味しない。
4. 構成団体は、個別に合意した場合を除き、他の構成団体の事業に係る経費又は債務を当然に負担するものではない。

### 第10条（脱退）

1. 構成団体は、所定の意思決定手続を経て、運営協議会に通知することにより脱退することができる。
2. 脱退に伴う共同事業、財産及び情報資産の取扱いについては、関係する構成団体間で協議する。
3. 脱退前に個別の合意によって生じた権利義務については、当該合意に従って取り扱う。

### 第11条（協力機関）

1. 本連合体は、その目的を達成するため、国内外の学術団体、研究機関、学術情報基盤機関その他の関係機関と協力関係を形成することができる。
2. 前項の協力関係は、本連合体への構成団体としての参加を意味しない。
3. 協力関係の内容及び実施方法については、運営協議会又は関係する構成団体間の合意に基づいて定める。

## 第4章　組織及び運営

### 第12条（運営協議会）

1. 本連合体の最高意思決定機関として、運営協議会を置く。
2. 運営協議会は、各構成団体が選出する代表委員各1名をもって構成する。
3. 各構成団体は、代表委員の代理者を定めることができる。
4. 運営協議会は、次の事項を審議し、決定する。

   (1) 本連合体の基本方針に関する事項

   (2) 共同事業及び学術交流活動に関する事項

   (3) 構成団体の参加に関する事項

   (4) 国内外の機関との連携に関する事項

   (5) 代表及び副代表の選任に関する事項

   (6) 事務局及び専門部会の設置に関する事項

   (7) 定款の変更及び解散に関する事項

   (8) その他、本連合体の運営上の重要事項

5. 運営協議会は、必要に応じて専門家及び関係者の意見を聴くことができる。

### 第13条（運営協議会の開催及び議決）

1. 運営協議会は、原則として年1回以上開催する。
2. 運営協議会は、構成団体総数の過半数の参加により成立する。
3. 議決権は各構成団体につき1票とし、通常の議事は出席構成団体の過半数の賛成により決する。
4. 新たな構成団体の参加については、第8条の規定による。
5. 定款の変更及び解散については、構成団体総数の4分の3以上の賛成を必要とする。
6. 構成団体に新たな財政的義務を課す場合には、当該構成団体の同意を必要とする。
7. 運営協議会は、対面、オンライン会議又は電磁的方法により開催することができる。
8. 運営協議会の議事については、その記録を作成し、構成団体間で共有する。

### 第14条（代表及び副代表）

1. 本連合体に代表1名及び副代表1名を置く。
2. 代表及び副代表は、運営協議会が選任する。
3. 代表及び副代表は、原則として異なる構成団体から選任する。
4. 代表は本連合体を代表し、運営協議会の議長を務める。
5. 副代表は代表を補佐し、代表に支障があるときはその職務を代行する。
6. 代表及び副代表の任期は2年とし、再任を妨げない。
7. 代表は、構成団体の明示的な同意なく、当該団体に新たな契約上又は財政上の義務を負わせる行為をしてはならない。

### 第15条（事務局及び専門部会）

1. 本連合体は、運営協議会の決定により、事務局及び必要な専門部会を設置することができる。
2. 事務局及び専門部会の設置、構成、役割及び運営方法は、運営協議会が定める。
3. 専門部会には、構成団体に所属する研究者、実践者のほか、必要に応じて外部の専門家等が参加することができる。
4. これらの運営に当たっては、特定の構成団体への恒常的な負担の集中を避けるよう配慮する。

---

## 第5章　学術情報及び運営の公正性

### 第16条（学術情報及び権利の取扱い）

1. 本連合体は、学術情報の共有及び流通に当たり、著作者、出版者その他の権利者の権利を尊重する。
2. 学術情報の紹介、共有及び再利用に当たっては、その出典、原資料及び識別情報を可能な限り明確にし、継続的な参照可能性の確保に努める。
3. 構成団体が保有又は管理する学術情報については、当該構成団体の方針及び権利関係を尊重する。
4. 共同事業により作成された情報資産の権利及び管理については、関係する構成団体の合意により定める。
5. 永続的識別子及びメタデータ標準等の具体的な活用方法については、学術的な必要性、国際的な動向及び構成団体の実情を踏まえて定める。

### 第17条（公正性及び情報公開）

1. 本連合体は、公正かつ透明な運営を行い、社会的信用の維持及び向上に努める。
2. 本連合体は、その目的、基本方針、構成団体及び活動に関する情報を適切に公開する。
3. 本連合体は、研究倫理及び学術的公正を尊重し、責任ある学術情報の流通と利用に努める。
4. 個人情報その他の保護を要する情報については、適用される法令及び関係する構成団体の規程に従って適切に管理する。

### 第18条（共同方針及び対外的な活動）

1. 本連合体は、その目的に関係する構成団体共通の課題について、運営協議会の決定により、共同の方針又は見解を形成し、公表することができる。
2. 全構成団体の総意として見解を公表する場合には、全構成団体の同意を必要とする。
3. 本連合体は、構成団体の合意に基づき、国内外の学術団体及び学術情報関連機関に対して、共同の活動又は連携を提案することができる。
4. 構成団体が独自に行う意見表明及び対外的な活動は、本連合体への参加によって制約されない。

---

## 第6章　経費及び資産

### 第19条（経費及び資産の管理）

1. 本連合体の活動に必要な経費は、構成団体間の合意に基づいて負担する。
2. 本連合体への参加自体を理由として、一律の会費又は経費負担義務を課さない。
3. 共同事業に必要な経費並びに契約、支出及び管理に関する責任は、関係する構成団体間の合意に基づいて定める。
4. 本連合体の活動に関連して取得又は作成された財産及び情報資産は、権利者及び管理責任者を明確にして管理する。
5. 本連合体は、活動によって生じた利益を構成団体に分配することを目的としない。

---

## 第7章　定款の変更及び解散

### 第20条（定款の変更）

本定款は、運営協議会における構成団体総数の4分の3以上の賛成をもって変更することができる。

### 第21条（解散）

1. 本連合体は、運営協議会における構成団体総数の4分の3以上の賛成をもって解散することができる。
2. 構成団体が1団体となった場合には、連合体としての継続の可否について速やかに協議する。
3. 解散に際しては、共同事業、財産及び情報資産の取扱いについて、関係する構成団体間で協議する。
4. 解散後も継続的な参照が望ましい学術情報については、可能な限りその参照可能性の確保に努める。

### 第22条（細則）

本定款に定めるもののほか、本連合体の運営に必要な事項は、運営協議会が別に定める。

## 附則

### 第1条（施行）

本定款は、設立時の構成団体がそれぞれの所定の手続により承認し、相互に合意した日から施行する。

### 第2条（設立時の構成団体）

設立時の構成団体は、次の2団体とする。

1. 一般社団法人教育システム情報学会（JSiSE）
2. 一般社団法人日本インスティテューショナル・リサーチ協会（JAIR）

### 第3条（設立時の運営）

設立時の代表、副代表及び事務局その他必要な運営事項については、設立時の構成団体の協議により定める。
